# Paper I compact exact certificates

This directory contains the compact, directly replayable evidence for the three nonnesting transitions used in Paper I.

## Contents

- `benchmark_receipt.json`: machine-readable claim and limitation receipt;
- `continuation_bfs.cpp`: exact primitive-rational BFS generator;
- `m1_to_m2.csv`, `m2_to_m3.csv`, `m3a_to_m4.csv`: shortest-hit layer profiles;
- `m3b_nohit_to162.csv`, `m3c_nohit_to162.csv`: exact no-hit profiles through the relevant horizon;
- matching `.err` files: generator progress logs;
- `EVIDENCE_BOUNDARY.md`: explicit separation between compact replayable evidence and the external global depth-162 payload.

Run the compact checker:

```bash
python scripts/paper_i/verify_receipt.py
```

Run the complete local replay and byte-compare the regenerated profiles:

```bash
bash scripts/paper_i/replay_exact.sh
```

The global first-hit computation through depth 162 is not regenerated by this compact replay. Its dependency is stated explicitly rather than silently simulated.
