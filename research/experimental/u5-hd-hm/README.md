## Evidence and asset policy

- Canonical reports and scientific summaries live in ordinary Git history.
- Generated PNGs, large tables and duplicate ZIP bundles are excluded.
- Exact names, sizes and SHA-256 values are recorded in asset manifests.
- Binary release assets belong in GitHub Releases and/or Zenodo.
- Missing release assets do not change the authority boundary.
- This branch must not update canonical RGΦ claims without a separate
  preregistered external-validation gate.
