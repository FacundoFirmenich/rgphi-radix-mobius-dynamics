# Single-defect Smith phase selection

Assume a strongly connected finite component has exactly one strict edge with defect

\[
d=\prod p^{a_p},
\]

all other edges have unit content, and some directed cycle traverses the strict edge once. The holonomy lattice is `L=Z a`, where `a=(a_p)`. If `g=gcd_p(a_p)`, then

\[
\operatorname{sat}(L)/L\cong\mathbb Z/g\mathbb Z.
\]

For the six-state high-defect candidates:

\[
\begin{array}{c|c|c}
d&\text{valuation vector}&\text{phase group}\\\hline
4&(2)&\mathbb Z/2\mathbb Z\\
5&(1)&0\\
6&(1,1)&0\\
7&(1)&0.
\end{array}
\]

Thus `d=4` is the unique candidate with a nontrivial intrinsic finite Smith phase. An actual `d=4` alternating-hexagon realization would carry a canonical binary torsion phase, distinct from the coherent-path hyperaccess key.

The two fully divisible `d=4` tuples found through `Q<=5000` fail CRT, so no realization is claimed.
