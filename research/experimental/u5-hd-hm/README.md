## Evidence and asset policy

- Canonical reports and scientific summaries live in ordinary Git history.
- HM-009 includes a full textual research archive because its source set was compact enough to preserve coherently in one file.
- Generated PNGs and duplicate ZIP bundles are intentionally excluded from ordinary Git history.
- Their exact names, sizes and SHA-256 values are recorded in [ASSET_MANIFEST.md](ASSET_MANIFEST.md).
- Binary release assets belong in GitHub Releases and/or Zenodo at archival freeze.
- A binary release is not considered complete until the uploaded assets match the recorded hashes.
- This branch must not update canonical RGΦ claims without a separate preregistered external-validation gate.
