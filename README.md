**RGΦ** is an exact research compendium for a noncommutative rational semigroup
generated by an integer-radix map and a Möbius-conjugate branch. The project
connects arithmetic dynamics, exact first-hit optimization, Farey geometry,
10-adic control, prime-wise reduction budgets, and finite modular traps.

The current public release centers on the submission-grade manuscript:

> **Nonnested extremal targets in a rational radix–Möbius semigroup**

## Main exact results

For the decimal benchmark with seed `17/19`, certified terminal convention, and
portal sets

\[
P_m(10,\kappa)=\{x:q(x)>\kappa 10^m\},\qquad
q(a/b)=\frac{b}{b-a},
\]

the exact first-hit times at `κ = 11` are

\[
(\tau_1,\tau_2,\tau_3,\tau_4)=(45,85,120,162).
\]

The corresponding first-hit states are **not nested Bellman optima**. Exact
continuations of the earliest states reach the next target at times `87`,
`139`, and `168`, strictly after the global optima `85`, `120`, and `162`.
This nonnesting is robust for

\[
\kappa\in[10.6197,11.01),
\]

while the complete four-level chronology remains unchanged for

\[
\kappa\in[10.6197,11.643).
\]

A companion line classifies finite modular traps. The exact eight-state trap

\[
C_8=\{1/13,3/13,4/13,5/11,6/11,9/13,10/13,12/13\}
\]

is forward-invariant modulo the certified terminal set and has maximum portal
height `13`. Consequently, every branch entering it before a deeper target has
infinite Bellman distance to that target.

The depth-five optimum remains open:

\[
179\le \tau_5\le 212.
\]

No claim in Paper I depends on closing this interval.

## Install and verify

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[dev]'
pytest
rgphi verify
```

The repository-level verifier checks the foundational conjugacy, base-family
identity, exact robustness intervals, C8 forward invariance, modular orders,
and canonical trap-atlas counts.

## Reproduce the finite trap atlas

```bash
python scripts/trap_atlas.py
# or
rgphi trap-atlas --denominator-bound 500
```

The reference atlas at denominator bound `500` contains:

- 76,094 nonterminal reduced rational states;
- 109,254 directed nonterminal edges;
- 23,176 strongly connected components;
- 153 SCCs closed modulo the terminal set;
- 1,502 exact finite forward-invariant closures.

## Reproducibility boundary

All reachability and target-membership decisions use primitive integer or exact
rational arithmetic. Floating-point values are presentation-only. Historical
large-scale searches additionally use independent engines, canonical sorted
state encodings, and SHA-256 fingerprints.

The repository distinguishes:

- proved symbolic identities;
- exact finite computer-assisted theorems;
- open conjectures and incomplete global searches;
- superseded witnesses that remain locally valid.

## Resumen en castellano

RGΦ estudia una dinámica racional exacta generada por una transformación radix
y una rama conjugada por Möbius. El resultado editorial principal demuestra
que los primeros objetivos extremales no forman una cadena óptima anidada y
que esa ruptura persiste en un intervalo exacto del parámetro de umbral. El
repositorio incluye el paper, los datos certificadores, el atlas de traps, el
código reproducible y los metadatos necesarios para GitHub, arXiv y Zenodo.
