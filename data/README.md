# Exact evidence data

- `thresholds/`: exact first-hit profiles, robust parameter intervals, latent
  precursors, and nonnesting continuation costs.
- `traps/`: the denominator-bound-500 finite-trap atlas, SCC classification,
  forward closures, and the exact C8 audit.
- `certificates/`: compact textual certificates and search summaries.

CSV and JSON values used for logical decisions are exact integers or rational
strings. Decimal floats are presentation fields only.
