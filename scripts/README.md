# Independent scripts

- `base_b_audit.py`: base-family symbolic and exact arithmetic checks.
- `trap_atlas.py`: standalone finite-trap atlas generator.
- `compact_bfs.cpp`: compact exact target-BFS kernel retained for auditability.
- `verify_legacy_unit.py`: verifier for the preceding scientific-unit bundle.

The installable package under `src/rgphi/` is the preferred small verifier.
