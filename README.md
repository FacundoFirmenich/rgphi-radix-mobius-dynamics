**RGΦ** is an exact mathematical and computational research program on a noncommutative rational dynamical system generated by an integer-radix transformation and a Möbius-conjugate branch. The project studies how modular arithmetic, primitive reduction, Farey geometry, hidden \(p\)-adic phase, dynamic programming, and finite recurrent structures interact in exact rational state spaces.

This repository is the **public research compendium** for the project. It contains the current manuscript, exact evidence tables, independent verification code, finite-trap atlas, literature-positioning material, reproducibility protocol, and release metadata.

> **Current archival status:** public release candidate, **not yet assigned a Zenodo DOI**.  
> A DOI will be minted only after the repository documentation, evidence map, and release metadata are frozen.

## 1. Scientific question

Let

\[
T_B(x)=\{Bx\},\qquad
H(x)=\frac{1}{1+x},\qquad
S_B=H\circ T_B\circ H^{-1},
\]

with integer base \(B\ge 2\), restricted to the admissible rational branches in \((0,1)\). The pair \((T_B,S_B)\) generates a noncommutative rational semigroup.

For a reduced rational \(x=a/b<1\), define the portal height

\[
q(x)=\frac{1}{1-x}=\frac{b}{b-a},
\]

and the parameterized extremal targets

\[
P_m(B,\kappa)=\{x:q(x)>\kappa B^m\}.
\]

The central questions are:

1. Which rational states minimize the first hitting time of deeper targets?
2. Do earliest extremal states remain optimal precursors for deeper targets?
3. Which hidden arithmetic coordinates determine future value when the visible rational state is insufficient?
4. Which branches escape toward increasingly extreme rational states, and which enter finite modular traps?
5. Which parts of these phenomena persist under changes of threshold, base, seed, and arithmetic context?

## 2. Main proved results

### 2.1 Exact first-hit chronology for the decimal benchmark

For \(B=10\), seed \(17/19\), \(\kappa=11\), and the certified terminal convention used throughout the benchmark,

\[
\boxed{
\tau_1=45,\quad
\tau_2=85,\quad
\tau_3=120,\quad
\tau_4=162.
}
\]

These values are produced by exact rational enumeration. No floating-point comparison participates in target membership or reachability.

### 2.2 Nonnested extremal targets

The earliest state reaching a target need not be the best precursor of the next target.

For the benchmark:

| source optimum | source time | next target reached by optimal continuation | global next-target optimum |
|---|---:|---:|---:|
| \(128/129\) | 45 | 87 | 85 |
| \(1202/1203\) | 85 | 139 | 120 |
| \(11156/11157\) | 120 | 168 | 162 |

Hence the sequence of first-hit states does **not** satisfy scalar Bellman optimal substructure.

In particular,

\[
\boxed{\text{portal depth and instantaneous height are not sufficient value coordinates.}}
\]

### 2.3 Exact threshold robustness

The complete four-level chronology

\[
(45,85,120,162)
\]

remains unchanged throughout

\[
\boxed{\kappa\in[10.6197,11.643).}
\]

The three consecutive nonnesting inequalities above persist simultaneously throughout

\[
\boxed{\kappa\in[10.6197,11.01).}
\]

Thus the principal Paper I phenomenon is not an artifact of tuning the single benchmark value \(\kappa=11\).

### 2.4 Finite modular traps

The radix map has the exact denominator law

\[
\operatorname{den}\!\left(T_B^n(a/q)\right)
=
\frac{q}{\gcd(q,B^n)}.
\]

After the \(B\)-primary denominator factors are removed, the remaining radix orbit is controlled by a multiplicative order modulo the coprime denominator component.

This yields a structural description of finite terminal-relative traps as:

\[
\boxed{
\text{radix preperiodic/cyclic skeleton}
+
\text{Möbius coupling}.
}
\]

A canonical example is

\[
C_8=
\left\{
\frac1{13},\frac3{13},\frac4{13},
\frac5{11},\frac6{11},
\frac9{13},\frac{10}{13},\frac{12}{13}
\right\},
\]

with

\[
\operatorname{ord}_{13}(10)=6,\qquad
\operatorname{ord}_{11}(10)=2.
\]

It is forward-invariant modulo the certified terminal set, has \(\max q=13\), and therefore gives the exact Bellman statement

\[
\boxed{V_5(7/260)=\infty.}
\]

### 2.5 Reference finite-trap atlas

For all reduced nonterminal rational states with denominator at most 500, the canonical atlas contains:

- **76,094** states;
- **109,254** directed nonterminal edges;
- **23,176** strongly connected components;
- **153** SCCs closed modulo the terminal set;
- **1,502** exact finite forward-invariant closures.

These are finite exact counts, not estimates.

## 3. What remains open

The repository intentionally distinguishes proved results from the active frontier.

The exact depth-five optimum is **not** claimed to be solved:

\[
\boxed{179\le \tau_5\le 212.}
\]

The current exact upper witness reaches

\[
\frac{1350416}{1350417}
\]

at global time 212. The earlier 217-step witness remains a valid local construction but is globally superseded.

Other open directions include:

- a family-level classification theorem for finite traps and their basins;
- a general theory of hidden Farey/\(p\)-adic control;
- base-\(B\) universality and failure modes;
- asymptotics of extremal hitting times;
- completion of the algebraic status of the contextual prime-wise semantics;
- independent external replication of the large computer-assisted certificates.

See [Scientific status](docs/SCIENTIFIC_STATUS.md) and [Open problems](docs/OPEN_PROBLEMS.md).

## 4. Why the project is not a “golden-ratio digit correlation”

The historical seed is linked to the projective chart

\[
H(x)=\frac1{1+x},
\]

whose matrix

\[
Q=
\begin{pmatrix}
0&1\\
1&1
\end{pmatrix}
\]

satisfies

\[
Q^2=Q+I
\]

and has eigenvalues \(\phi\) and \(-\phi^{-1}\).

The legitimate role of the golden ratio is therefore **operatorial and spectral**. This repository makes **no claim of a direct correlation between the decimal digits of \(\phi\) and the benchmark rational orbits**.

## 5. Evidence model

Every scientific statement in the repository belongs to one of four evidence classes:

| Class | Meaning | Typical evidence |
|---|---|---|
| **S — symbolic** | proved algebraically | theorem/proof and exact unit test |
| **F — finite exhaustive** | complete finite search | exact enumeration, counts, canonical hashes |
| **C — computer-assisted large** | exact but computationally heavy | independent engines, checksums, search certificates |
| **O — open** | not proved | explicit interval, conjecture, or research question |

Claims are never promoted from one class to another without a corresponding proof artifact.

See [Evidence model](docs/EVIDENCE_MODEL.md).

## 7. Reproduce the core results

### Fast verification

~~~bash
git clone https://github.com/FacundoFirmenich/rgphi-radix-mobius-dynamics.git
cd rgphi-radix-mobius-dynamics

python -m venv .venv
source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -e '.[dev]'

pytest
ruff check src tests
rgphi verify
~~~

The continuous-integration matrix runs under Python 3.11 and 3.12.

### Rebuild the trap atlas

~~~bash
python scripts/trap_atlas.py
# or
rgphi trap-atlas --denominator-bound 500
~~~

### Compile the manuscript

~~~bash
cd paper
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
~~~

## 9. Literature and novelty boundary

RGΦ does not claim to invent radix transformations, Möbius maps, Farey dynamics, \(p\)-adic symbolic structure, dynamic programming, open dynamical systems, or modular cycles individually.

The research claim concerns their exact interaction in this rational semigroup, especially:

- robust nonnested extremal targets;
- arithmetic counterexamples to naive scalar Bellman summaries;
- hidden Farey/\(p\)-adic control mechanisms;
- prime-wise reduction budgets;
- finite modular traps with exact non-escape consequences.

The current literature audit is a **priority-risk analysis**, not a declaration of absolute priority. Before journal submission, closed bibliographic databases and specialist review remain desirable.

See [Literature audit](docs/literature/literature-priority-audit.md).
