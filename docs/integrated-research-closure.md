# RGΦ — Integrated research closure

**Canonical date:** 27 October 2026  
**Scope:** integrated scientific state of the research program  
**Status:** first publication-grade phase closed; depth-five global optimum remains open

## Executive synthesis

RGΦ should not be understood as a long computation aimed at deciding one hitting time. It is a mathematical-computational program on a noncommutative rational dynamical system in which five structures interact:

1. integer-radix and modular dynamics;
2. Möbius/Fibonacci conjugacy;
3. Farey geometry and primitive reduction;
4. hidden \(p\)-adic/prime-wise arithmetic context;
5. Bellman extremal targets, escape, recurrence, and finite trapping.

The central object is the rational semigroup generated by

\[
T_B(x)=\{Bx\},
\qquad
S_B=H\circ T_B\circ H^{-1},
\qquad
H(x)=\frac1{1+x}.
\]

For the decimal benchmark, the project has produced exact first-hit theorems, robust nonnesting counterexamples, finite modular traps, and a reproducible computer-assisted framework.

## 1. Foundational bridge

Let

\[
C(x)=x^{-1}-1.
\]

Then

\[
C(17/19)=2/17,\qquad
C(17/20)=3/17,
\]

and

\[
T_{10}(2/17)=3/17.
\]

Therefore

\[
C(17/20)=T_{10}(C(17/19)).
\]

The map \(H(x)=(1+x)^{-1}\) transports the radix dynamics back to the benchmark interval.

The projective matrix

\[
Q=
\begin{pmatrix}
0&1\\
1&1
\end{pmatrix}
\]

satisfies

\[
Q^2=Q+I.
\]

This is the legitimate Fibonacci/golden-ratio connection. No digit-correlation claim is made.

## 2. Noncommutative rational dynamics

The branch matrices have determinant \(B\), and the \(T_B\) and \(S_B\) actions do not commute in general.

This matters because the order of radix and conjugate operations carries arithmetic information that cannot be summarized by a single monotone observable.

## 3. Extremal targets

For reduced \(x=a/b<1\),

\[
q(x)=\frac{b}{b-a}.
\]

Define

\[
P_m(B,\kappa)=\{x:q(x)>\kappa B^m\}.
\]

For the decimal benchmark with \(\kappa=11\),

\[
\tau_1=45,\quad
\tau_2=85,\quad
\tau_3=120,\quad
\tau_4=162.
\]

The first-hit states are not nested optimal precursors. This is not merely a numerical curiosity: it gives an explicit arithmetic failure of scalar optimal substructure.

## 5. Visible height is not a sufficient value coordinate

The continuation experiments show that states with very large current portal height can be inferior to states with much lower height but more favorable arithmetic phase.

The scientific conclusion is not merely “greedy search fails.” It is:

> future extremal value is carried by arithmetic position and phase information that is not captured by the scalar height \(q(x)\).

This motivates the hidden-state line of the program.

## 6. Farey and prime-wise control

Primitive reduction and Farey-neighbor data produce exact cocycle-like accounting laws. In the decimal case, prime factors \(2\) and \(5\) govern the reduction budget.

This line has generated strong exact evidence of history-dependent control, including trajectories that share long visible behavior but diverge under distinct hidden arithmetic phase.

The public repository treats this as a high-value research direction rather than an already generalized theorem.

## 7. Finite modular traps

The discovery of the finite set \(C_8\) changed the strategic interpretation of the project.

Instead of proving “no hit before a finite horizon,” a finite forward-invariant set can prove **no escape at any future time**.

The radix denominator theorem explains the modular skeleton:

\[
\operatorname{den}(T_B^n(a/q))
=
q/\gcd(q,B^n).
\]

The Möbius branch couples those modular components.

Thus finite traps are not accidental enumerated objects; they have a structural arithmetic mechanism.

## 8. Depth-five status

The exact global value remains open:

\[
179\le\tau_5\le212.

The upper endpoint is witnessed constructively. The lower endpoint is rigorous.

The previous 217-step witness is retained as a locally valid but globally superseded result.

## 9. Contextual prime-wise semantics

Local prime-wise allocation modes possess a natural Boolean complement structure.

However, the global pasted object has not been proved to satisfy the axioms of an orthomodular poset or orthomodular lattice.

The canonical public term is therefore:

> orthocomplemented contextual prime-wise budget semantics.

This is a deliberate correction of earlier internal terminology.
