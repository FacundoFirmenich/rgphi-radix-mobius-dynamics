# Teorema-marco T009-C — Codo Real como gauge latente

## 1. Dato metrológico histórico

El Codo Real egipcio se documenta aproximadamente en 52.3–52.5 cm y se subdivide en

\[
\boxed{7\text{ palmas}=28\text{ dedos}.}
\]

Este dato histórico se usa únicamente como procedencia de una elección de gauge.

## 2. Línea de escala

Sea \(L\) una línea real de unidades de longitud y sea \(c_R\in L\), \(c_R\neq0\), la sección elegida como Codo Real. Definimos el dedo metrológico

\[
\epsilon_R=\frac{c_R}{28}.
\]

Para una magnitud longitudinal \(x\), sus coordenadas adimensionales son

\[
\widehat x=\frac{x}{c_R},
\qquad
\widetilde x=\frac{x}{\epsilon_R}=28\widehat x.
\]

## 3. Latencia

Si cada plano usa \(c_R\) para adimensionalizar su métrica,

\[
\bar g_M=c_R^{-2}g_M,
\qquad
\bar g_m=c_R^{-2}g_m,
\]

entonces \(c_R\) desaparece de los productos internos adimensionales. En ese sentido preciso permanece latente: fija el gauge, hace comparables las coordenadas y no aparece como término dinámico.

## 4. Ortonormalización para observadores

Decir que el gauge sirve para cualquier observador no significa que sus componentes numéricas sean iguales bajo una transformación arbitraria. La afirmación covariante correcta es

\[
g'_O=J_O^{-T}g_OJ_O^{-1}.
\]

Cada observador puede elegir un frame \(E_O\) tal que

\[
E_O^T(c_R^{-2}g_O)E_O=I.
\]

Por tanto, el Codo Real puede ser un gauge común, pero la métrica debe transformarse covariantemente.

## 5. Actualización interanidación

El gauge se vuelve correlacionalmente efectivo cuando se compara una fase discreta entre planos:

\[
\phi_R(x)=\frac{x}{\epsilon_R}\pmod{28}.
\]

La diferencia

\[
\Delta\phi_R=\phi_R(x_M)-\phi_R(x_m)\pmod{28}
\]

es invisible mientras los planos no se comparan. Al activar la UMI, se convierte en observable de acoplamiento.

## 6. Boundary

Este modelo no afirma que \(c_R\) sea una constante física universal. Afirma algo más limitado:

\[
\boxed{c_R\text{ puede actuar como sección común de gauge};\quad\Delta\phi_R\text{ puede actuar como fase de interanidación}.}
\]
