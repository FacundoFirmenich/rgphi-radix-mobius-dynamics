# Hyperaccess as a vanishing qualitative phase key

Let `X_N` be a full completion object, `O_N` an observation and `K_N` a qualitative key. `K_N` is an exact hyperaccess key when:

1. `X_N` is not determined by `O_N`;
2. `X_N` is determined by `(O_N,K_N)`;
3. the normalized key cost tends to zero;
4. distinct keys select completions with macroscopically separated or diverging lifted states.

## Exact RGΦ coherent-phase family

Consider

\[
W_N^{(0)}=(TTTT)^N,
\qquad
W_N^{(1)}=(TSTS)^N.
\]

They have the same start, endpoint and length `4N`, while their terminal receipts are `0` and `N e_3`; their log-radial separation is `N log 3`.

One bit selects the coherent phase. Hence

\[
H(K_N)=1\text{ bit},
\qquad
\kappa_N=1/(4N)\to0,
\]

while the completion gain `N log 3` diverges.

If the `N` blocks vary independently, complete recovery requires `N` bits: that is superaccess. If one global qualitative phase selects all blocks, one bit synchronizes the complete lift: that is hyperaccess.

\[
\boxed{\text{superaccess recovers hidden contents; hyperaccess selects the completion phase}.}
\]
