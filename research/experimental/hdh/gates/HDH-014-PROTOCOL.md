# HDH-014 — Preregistered protocol

## Name
Kernel-Field Dynamics, Causal Composition and Constitutive Fixed Points

## Required gates
1. treat the positive constitutive kernel `K` as a state field, not a fitted scalar;
2. derive a procedural evolution compatible with the exact Schur rank-one RG update;
3. couple `K` to causal-order interval abundances without importing a continuum metric;
4. test whether a low-dimensional spectral-measure closure is stable across sphere, torus, defects and causal-set holdouts;
5. require positivity, composition, retarded propagation and gauge/automorphism covariance;
6. compare with Benincasa-Dowker or newer causal-set operators only as frozen external benchmarks;
7. use an independent checker and negative controls.

## Explicit failure
The gate fails if a kernel family is selected after holdout inspection, if physical time is identified with RG scale, or if a continuum Einstein operator is inserted as a hidden target.
