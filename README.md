**RGΦ** is an exact mathematical and computational research program on a noncommutative rational dynamical system generated by an integer-radix transformation and a Möbius-conjugate branch. It studies extremal first hitting, Bellman value, Farey geometry, prime-wise reduction budgets, finite modular traps, and exact external-memory certification.

This repository is the public research compendium for the project. It contains the current manuscript, exact evidence tables, reference implementations, finite-trap atlas, large-search certificates, reproducibility material, and release metadata.

> **Archival status:** public pre-DOI release candidate. No Zenodo DOI has yet been minted.

## 1. System and scientific question

For integer base \(B\ge2\),

\[
T_B(x)=\{Bx\},\qquad
H(x)=\frac1{1+x},\qquad
S_B=H\circ T_B\circ H^{-1}.
\]

For reduced \(x=a/b<1\), define

\[
q(x)=\frac{1}{1-x}=\frac{b}{b-a},
\qquad
P_m(B,\kappa)=\{x:q(x)>\kappa B^m\}.
\]

The principal questions are:

1. Which rational states minimize first hitting times of deeper targets?
2. Do earliest extremal states remain optimal precursors for later targets?
3. Which arithmetic coordinates are required for Markov-complete value prediction?
4. Which branches escape toward extreme states, and which enter finite modular traps?
5. Which parts persist under changes of threshold, base, seed, and arithmetic context?

## 2. Closed benchmark results

For \(B=10\), seed \(17/19\), \(\kappa=11\), and the certified terminal convention,

\[
\boxed{
\tau_1=45,\quad
\tau_2=85,\quad
\tau_3=120,\quad
\tau_4=162.
}
\]

The earliest states are not nested Bellman precursors:

\[
45\to87>85,\qquad
85\to139>120,\qquad
120\to168>162.
\]

Thus portal depth and instantaneous height are not sufficient value coordinates.

The four-level chronology remains unchanged throughout

\[
\boxed{\kappa\in[10.6197,11.643),}
\]

and all three nonnesting inequalities persist throughout

\[
\boxed{\kappa\in[10.6197,11.01).}
\]

## 3. Finite modular traps

The exact denominator law

\[
\operatorname{den}(T_B^n(a/q))=\frac{q}{\gcd(q,B^n)}
\]

shows how the \(B\)-primary denominator component is removed before the coprime component enters a radix cycle controlled by a multiplicative order.

A canonical terminal-relative trap is

\[
C_8=\{1/13,3/13,4/13,5/11,6/11,9/13,10/13,12/13\},
\]

which gives the exact Bellman statement

\[
\boxed{V_5(7/260)=\infty.}
\]

The denominator-500 reference atlas contains exactly:

- 76,094 nonterminal states;
- 109,254 directed nonterminal edges;
- 23,176 strongly connected components;
- 153 SCCs closed modulo the terminal set;
- 1,502 exact finite forward-invariant closures.

These are finite exact counts, not a global trap-classification theorem.

## 5. Active frontier: Stage B2

Stage B2 propagates the complete exact level envelope from time 185 through time 211.

- A hit yields a shorter exact witness.
- No hit through 211 proves \(\tau_5=212\).
- Combined with the complete first-divergence classification, no hit completes the Bellman ladder along the witness for \(0\le t\le212\).

The repository now includes:

- strict validation of all checkpoint hashes and structural invariants;
- an exact C++ external-memory worker and multiway merger;
- transactional per-level commits and resumability;
- target-before-pruning semantics;
- an independent exact smoke comparison;
- a production runbook and explicit blocker receipt.

Start with [the Stage B2 runbook](docs/STAGE_B2_RUNBOOK.md).

Production remains blocked solely by locating or mounting the exact 128 raw checkpoint buckets on a filesystem with sufficient free space. The code does not regenerate or fabricate the missing checkpoint.

## 6. Why RGΦ is not a digit-correlation claim

The historical seed is linked to

\[
H(x)=\frac1{1+x},
\]

whose projective matrix

\[
Q=\begin{pmatrix}0&1\\1&1\end{pmatrix}
\]

satisfies \(Q^2=Q+I\) and has eigenvalues \(\phi\) and \(-\phi^{-1}\).

The legitimate role of the golden ratio is operatorial and spectral. The project makes no claim of a direct correlation between the decimal digits of \(\phi\) and the benchmark orbit.

## 11. Novelty boundary

RGΦ does not claim to invent radix transformations, Möbius maps, Farey dynamics, \(p\)-adic symbolic structures, dynamic programming, open dynamical systems, or modular cycles individually.

The research claim concerns their exact interaction in this rational semigroup, especially:

- robust nonnested extremal targets;
- arithmetic counterexamples to naive scalar Bellman summaries;
- hidden Farey/\(p\)-adic control mechanisms;
- prime-wise reduction budgets;
- finite modular traps with exact non-escape consequences;
- exact large-search certification of rare extremal access.
