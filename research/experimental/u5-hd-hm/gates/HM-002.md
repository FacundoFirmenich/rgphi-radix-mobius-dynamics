# U5-HD-HM-002 — Completación diédrica gauge y flujo de reflexión inevitable

## Veredicto

\[
\boxed{\texttt{PASS\_CASE\_B\_WITH\_UNAVOIDABLE\_Z2\_FLUX}}
\]

El grupo diédrico \(D_5=\mathbb Z_5\rtimes\mathbb Z_2\) permite pegar coherentemente las cartas pentádicas locales, pero no aplana la obstrucción triangular del dual. La obstrucción reaparece como un campo gauge de reflexiones \(\mathbb Z_2\).

## 1. Grupo local

Los elementos \((a,\varepsilon)\), con \(a\in\mathbb Z_5\), \(\varepsilon\in\{\pm1\}\), actúan por

\[
r\mapsto \varepsilon r+a\pmod5,
\]

y satisfacen \(R^5=I\), \(D^2=I\), \(DRD^{-1}=R^{-1}\).

## 2. Regla de costuras

Una arista compartida debe ser costura para ambas caras o no-costura para ambas. Las costuras internas forman un matching en el grafo dual.

## 3. Flujo triple

En un triángulo dual:

- si contiene una costura, la holonomía puede ser la identidad;
- si no contiene costura, la holonomía es una reflexión no trivial de orden dos.

La clase reflexión/identidad es gauge-invariante.

## 4. Escalamiento

Para el parche hexagonal de radio \(R\),

\[
F_R=1+3R(R+1),\qquad T_R=6R^2.
\]

La optimización exacta produce, para \(R\ge2\),

\[
N_{\rm plano}(R)=F_R-4,
\]

\[
N_{\rm flujo}(R)=3(R^2-R+1),
\]

\[
\rho_R=\frac{R^2-R+1}{2R^2}\longrightarrow\frac12.
\]

La densidad mínima de flujo en la malla infinita es exactamente \(1/2\).

## 5. Cobertura ramificada

Si la reflexión se interpreta como intercambio de hojas, los vértices frustrados son puntos de ramificación de una doble cobertura. La estructura helicoidal completa requiere

\[
G_{\rm hel}=(\mathbb Z\times\mathbb Z_5)\rtimes\mathbb Z_2,
\]

con inversión simultánea del nivel y de la fase.

## 6. Decisión A/B/C

- A — D5 elimina la obstrucción: refutada.
- B — D5 permite el pegado local con flujo no trivial: demostrada.
- C — ampliación local obligatoria: no necesaria para este gate.

## 7. Cortafuegos

La construcción permanece `EXPERIMENTAL_ISOLATED`. No identifica automáticamente reflexión gauge, chirialidad ontológica, spin físico ni estructura del espacio-tiempo.
