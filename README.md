**RGΦ** is an exact mathematical and computational research program on a noncommutative rational semigroup generated by an integer-radix map and a Möbius-conjugate branch. The project studies extremal first-hitting problems, finite modular traps, hidden Farey and prime-wise reduction coordinates, and exact Bellman certification.

This repository is the public research compendium for the canonical RGΦ mainline. It contains the manuscript, exact evidence tables, reference implementations, verification code, trap atlases, literature-positioning material, reproducibility protocols, and archival metadata.

> **Current status:** public pre-DOI release candidate. No Zenodo DOI has yet been assigned.

## 1. Dynamical system

For an integer base \(B\ge2\),

\[
T_B(x)=\{Bx\},\qquad
H(x)=\frac1{1+x},\qquad
S_B=H\circ T_B\circ H^{-1}.
\]

For a reduced rational \(x=a/b<1\), define

\[
q(x)=\frac{1}{1-x}=\frac{b}{b-a}
\]

and the extremal targets

\[
P_m(B,\kappa)=\{x:q(x)>\kappa B^m\}.
\]

The benchmark jurisdiction is

\[
B=10,\qquad x_0=\frac{17}{19},\qquad \kappa=11.
\]

## 4. Finite modular traps

The radix denominator law is

\[
\operatorname{den}(T_B^n(a/q))=\frac{q}{\gcd(q,B^n)}.
\]

A canonical terminal-relative trap is

\[
C_8=\left\{\frac1{13},\frac3{13},\frac4{13},\frac5{11},\frac6{11},\frac9{13},\frac{10}{13},\frac{12}{13}\right\},
\]

with maximum portal height 13. Therefore

\[
\boxed{V_5(7/260)=\infty.}
\]

The reference atlas for denominator bound 500 contains exactly:

- 76,094 nonterminal rational states;
- 109,254 directed nonterminal edges;
- 23,176 strongly connected components;
- 153 SCCs closed modulo the terminal set;
- 1,502 exact finite forward-invariant closures.

## 5. Role of the golden ratio

The project does not claim a decimal-digit correlation with \(\phi\). The legitimate connection is operatorial and spectral. The Möbius chart is represented by

\[
Q=\begin{pmatrix}0&1\\1&1\end{pmatrix},\qquad Q^2=Q+I,
\]

with eigenvalues \(\phi\) and \(-\phi^{-1}\). The rational system also contains an exact Fibonacci-renewal trap. These are mathematical identities, not numerological claims.

## 7. Program topology and authority

The repository uses explicit branch governance:

- **RGΦ mainline — `CANONICAL_ACTIVE`**: may update canonical scientific claims.
- **Paper I — `PUBLICATION_TRACK`**: nonnested extremal targets; independent of the exact value of \(\tau_5\).
- **RGΦ-GEN — `PARALLEL_ISOLATED`**: base/seed/target generalization with preregistered holdouts.
- **Artin–Kummer — `PARALLEL_ISOLATED`**: separate arithmetic specialization.
- **U5-HD/HM — `EXPERIMENTAL_ISOLATED`**: abstract mathematical exploration with no retroactive authority over RGΦ.

The archived U5-HD-HM gates are available under [research/experimental/u5-hd-hm](research/experimental/u5-hd-hm/README.md). Their PASS results establish only the stated internal mathematics of the selected models; they do not establish physical, cosmological, ontological, or predictive validity.

## 9. Reproduction

```bash
git clone https://github.com/FacundoFirmenich/rgphi-radix-mobius-dynamics.git
cd rgphi-radix-mobius-dynamics
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[dev]'
pytest
ruff check src tests
rgphi verify
```

To rebuild the finite-trap atlas:

```bash
python scripts/trap_atlas.py
# or
rgphi trap-atlas --denominator-bound 500
```

## 11. Novelty boundary

RGΦ does not claim to invent radix transformations, Möbius maps, Farey dynamics, p-adic structure, dynamic programming, or modular cycles separately. The contribution concerns their exact interaction in this rational control system, especially:

- robust nonnested extremal targets;
- arithmetic counterexamples to naive scalar Bellman summaries;
- hidden Farey and prime-wise reduction mechanisms;
- finite modular traps with exact non-escape consequences;
- reproducible computer-assisted certification.
