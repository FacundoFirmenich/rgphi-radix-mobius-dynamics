# Epistemic-observational experimental branch

**Authority:** `EXPERIMENTAL_ISOLATED`

EO studies partial observers, finite resolution, transition maps, higher
cocycles, nonunique completions and active refinement policies. It formalizes
the difference between:

- coverage of a base complex;
- compatibility on overlaps;
- existence of a global coarse class;
- uniqueness of exact lifts;
- agent-selected resolution gain.

| Gate | Result |

| EO-001 | compatible local atlas, four exact lifts, triple-cocycle obstruction, active policy `4→2→1` |

EO-001 is a finite formal model. It does not establish an ontology of
