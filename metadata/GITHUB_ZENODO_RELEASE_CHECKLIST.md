- [ ] Push `main` and tag `v1.0.0-rc.1`.
- [ ] Confirm CI and paper workflows pass.
- [ ] Connect GitHub to Zenodo and enable this repository.
- [ ] Confirm Zenodo reads `CITATION.cff` and `.zenodo.json`.
- [ ] Create a GitHub release from the tag.
- [ ] Inspect the Zenodo draft, upload any large archival companion files if needed, and publish.
- [ ] Record both version DOI and concept DOI.
