# Teorema T010-E RC1 — Hiperacceso tripolar corregido

La forma normalizada es

\[
\frac{14}{15},\qquad1,\qquad\frac{16}{15}.
\]

Si la observación no resuelve diferencias relativas de `1/15`, las tres ramas se identifican en un mismo datum. La fibra observacional tiene cardinalidad tres.

La llave zero-error mínima requiere

\[
\boxed{\lceil\log_2 3\rceil=2\text{ bits}}
\]

en codificación binaria fija, o un trit nativo

\[
\boxed{K=\sigma\in\{-1,0,+1\}.}
\]

Para una torre coherente de profundidad \(N\), una sola llave tripolar mantiene coste constante y tasa

\[
\boxed{\frac{\log_2 3}{N}\to0.}
\]

Las separaciones absolutas escalan:

\[
|U_{n,\pm}-U_{n,0}|=\frac{\pi}{9}10^n,
\]

\[
|U_{n,+}-U_{n,-}|=\frac{2\pi}{9}10^n.
\]

La llave de coste relativo nulo selecciona ramas cuya separación crece decádicamente.
