# Security policy

RGΦ is research software, not a network service. Security reports should focus
on supply-chain integrity, malicious files, command injection, unsafe archive
handling, or provenance tampering.

Please report vulnerabilities privately to f.firmenich@cedesur.org and include:

- affected version or commit;
- reproduction instructions;
- potential impact;
- suggested mitigation when known.

Do not include secrets or private data in public issues.
