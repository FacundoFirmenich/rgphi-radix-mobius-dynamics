# T006-A — content cohomology and alias lattices

Let a finite all-high SCC have vertex set `V`, labelled edge multiset `E`, and prime-valuation receipt
\[
a_e=(v_p(\delta_e))_{p\mid B}\in\mathbb Z_{\ge0}^{\omega(B)}.
\]
Let
\[
\partial:\mathbb Z^E\to\mathbb Z^V,\qquad \partial e=t(e)-s(e)
\]
and let `W` send the basis edge `e` to `a_e`.

## Holonomy lattice

Define
\[
Z_1(G)=\ker\partial,\qquad \mathcal L_F=W(Z_1(G)).
\]
Since a labelled SCC on `n` vertices has `2n` edges,
\[
\operatorname{rank}Z_1(G)=n+1,
\]
so
\[
\boxed{\operatorname{rank}\mathcal L_F\le\min(\omega(B),n+1).}
\]
Directed cycles generate the integer circulation group, so `L_F` is precisely the lattice generated by directed-cycle receipt vectors.

## Equal-length alias lattice

Let `ell(e)=1` and define
\[
\mathcal L_F^{(0)}=W(\ker\partial\cap\ker\ell).
\]
Then
\[
\boxed{\operatorname{rank}\mathcal L_F^{(0)}\le\min(\omega(B),n).}
\]
It is the group of receipt differences realizable by pairs of closed walks with the same base point and length, after adding a common positive circulation when necessary.

## Gauge invariance

The replacement
\[
a_e\mapsto a_e+\phi(t(e))-\phi(s(e))
\]
does not alter any cycle period. The content obstruction is therefore a graph-cohomology class with coefficients in the prime valuation lattice.

## Known five-state component

Five simple cycles have zero receipt and the strict `TSTS` cycle has receipt `e_3`. Therefore
\[
\boxed{\mathcal L_F=\mathbb Z e_3.}
\]
The equal-length words `TTTT` and `TSTS` differ by `e_3`, hence
\[
\boxed{\mathcal L_F^{(0)}=\mathbb Z e_3.}
\]
Both ranks are one.
