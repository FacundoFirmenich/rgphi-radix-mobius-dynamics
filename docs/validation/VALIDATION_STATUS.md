# Validation status — pre-DOI gate

**Canonical date:** 28 October 2026  
**Archival decision:** **HOLD** until genuine external mathematical evidence closes Gate C.

The project now distinguishes three different quantities that must not be conflated:

1. **validation infrastructure readiness** — whether an independent reviewer can inspect and reproduce the work;
2. **literature-positioning quality** — whether nearest prior art has been identified and claims are conservatively framed;
3. **external validation evidence** — reports and replications actually produced by independent people.

## Why external evidence remains 4.0

The repository now includes:

- an adversarial internal referee simulation;
- a focused referee bundle generated by CI and pinned to a commit;
- reviewer and replication templates;
- conflict-of-interest and independence policy;
- a machine-readable exact-output oracle;
- a public reviewer nomination matrix;
- deterministic CI, metadata audit, and exact reference verification;
- public GitHub issues tracking the campaign.

These make the project exceptionally review-ready. They do **not** constitute external validation.

The following do not count as independent evidence:

- author self-review;
- AI-assisted critique;
- GitHub CI;
- an implementation produced inside the same research workflow;
- literature searches performed by the authoring team;
- personal support without a written mathematical assessment.

## Gate-C passing condition

External mathematical validation reaches 9/10 only when all of the following exist on a pinned commit:

1. one independent review in dynamics / continued fractions / projective systems;
2. one independent review in arithmetic dynamics / number theory;
3. zero unresolved critical issues;
4. every major issue corrected, evidenced, or removed from the claim set;
5. one independent clean-room implementation reproducing the core finite theorem stack;
6. an explicit publication verdict from each mathematical reviewer.

## Literature gate

The open-source and current-frontier audit is now strong enough for specialist scrutiny. The remaining closure tasks are:

- MathSciNet and full zbMATH citation chaining for the highest-risk clusters;
- two specialist answers to the exact priority questions;
- incorporation of any closer precedent into the claim map and manuscript;
- version-pinned confirmation that the novelty wording is fair.
